# ملف التعريف الشخصي - مروان يحيى حسن غازي

موقع ويب تعريفي شخصي عالي الأداء، ثنائي اللغة (الإنجليزية والعربية) مبني باستخدام React 19 و Tailwind CSS v4. يعرض هذا المشروع أعمال ومهارات والفلسفة المهنية لمروان يحيى حسن غازي، مطور واجهات أمامية وتطبيقات سطح مكتب أول ومهندس برمجيات.

## 🌟 التجربة البصرية

![معاينة الموقع](https://placehold.co/1200x630/0f172a/ffffff?text=Marwan+Yahya+Hassan+Ghazi+Portfolio\nBilingual+High-Performance+Design)

يتميز ملف التعريف بتصميم بصري "أسطوري" مع:
- **مؤشر ماوس مخصص ومتحرك:** مؤشر تفاعلي يتتبع الحركة ويتغير حجمه عند الحوم فوق العناصر التفاعلية.
- **مؤشر تقدم التمرير:** شريط تقدم متدرج في أعلى نافذة العرض يتتبع تقدم القراءة (يدعم RTL/LTR).
- **قسم Hero ديناميكي:** أشكال خلفية عائمة مع حركة سائلة مستمرة ورسوم متحركة متداخلة عند الدخول.
- **رسوم متحركة متقدمة للتمرير:** استخدام Framer Motion لمراقبة التقاطع للكشف عن المحتوى بسلاسة أثناء التمرير.
- **تفاعل البطاقات عند الحوم:** تتميز البطاقات في أقسام المهارات والمشاريع بتأثيرات "الإمالة" و "التوهج" مع انتقالات ظلية متطورة.

## 🚀 المميزات

-   **دعم ثنائي اللغة (EN/AR):** تعريب كامل باستخدام `i18next` مع تبديل تلقائي للاتجاه (LTR/RTL).
-   **الوضع الداكن/الفاتح:** تبديل سلس للسمات باستخدام Tailwind CSS v4.
-   **لوحة تحكم لإدارة المحتوى:** لوحة تحكم مدمجة للمسؤول لتحديث المحتوى في الوقت الفعلي دون لمس الكود.
-   **تحسينات عالية الأداء:** تنفيذ تقنيات متقدمة مثل دمج الأحداث (event coalescing) للتفاعلات السلسة.
-   **تصميم متجاوب:** تخطيط متجاوب تماماً مع الهاتف المحمول باستخدام CSS Grid و Flexbox الحديث.
-   **فلسفة "خالٍ من الأخطاء":** مبني بهندسة نظيفة ومعيارية لضمان القوة والقابلية للتوسع.

## 🛠️ التقنيات المستخدمة

-   **الواجهة الأمامية:** [React 19](https://react.dev/)
-   **التنسيق:** [Tailwind CSS v4](https://tailwindcss.com/)
-   **الرسوم المتحركة:** [Framer Motion](https://www.framer.com/motion/)
-   **التعريب:** [i18next](https://www.i18next.com/) & [react-i18next](https://react.i18next.com/)
-   **الأيقونات:** [Lucide React](https://lucide.dev/) & أيقونات SVG مخصصة
-   **أداة البناء:** [Vite](https://vitejs.dev/)

## 📂 هيكل المشروع

```text
src/
├── assets/          # الصور والملفات الثابتة
├── components/      # مكونات واجهة المستخدم
│   ├── admin/       # مكونات لوحة تحكم الإدارة
│   ├── common/      # المكونات المشتركة (مثل المؤشر المخصص)
│   ├── layout/      # مكونات التخطيط (التذييل، شريط التنقل)
│   └── sections/    # أقسام الصفحة الرئيسية (البطل، عني، المهارات، إلخ)
├── context/         # React Context لإدارة الحالة
├── icons/           # الأيقونات المخصصة والمكتبات
├── styles/          # ملفات التنسيق العالمية
├── translations/    # ملفات التعريب (i18n)
├── App.jsx          # نقطة دخول التطبيق الرئيسية
├── i18n.js          # إعدادات i18next
└── main.jsx         # نقطة دخول Vite
```

## ⚙️ البدء

### المتطلبات المسبقة

-   Node.js (يوصى بأحدث إصدار LTS)
-   npm

### التثبيت

1.  استنساخ المستودع:
    ```bash
    git clone <repository-url>
    ```
2.  تثبيت التبعيات:
    ```bash
    npm install --legacy-peer-deps
    ```
    *ملاحظة: يوصى بـ --legacy-peer-deps بسبب الإصدارات الصارمة في بعض التبعيات.*

3.  بدء خادم التطوير:
    ```bash
    npm run d""ev
    ```

### البناء للإنتاج

لإنشاء بناء للإنتاج:
```bash
npm run b""uild
```
سيتم إخراج النتيجة في دليل dist/.
